# Angular REST Posts Application

An Angular learning project demonstrating HTTP communication with a REST API.

## Overview
This application explores making HTTP requests from an Angular frontend and presenting remote post data. Review the services and components to see the exact API source, operations, and error handling implemented.

## Technology
- Angular
- TypeScript
- RxJS / Angular HttpClient
- HTML and CSS
- Node.js and npm

## Prerequisites
- Node.js compatible with the Angular version declared in the project
- npm

## Getting Started
```bash
git clone https://github.com/MahiTzy/angular-rest-posts-app.git
cd angular-rest-posts-app
npm install
npx ng serve
```
Open [http://localhost:4200](http://localhost:4200).

## Development
Review the Angular service layer for API URLs and request methods. Check the browser network panel when troubleshooting failed requests or unexpected responses.

## Common Commands
- `npx ng build` — build the application.
- `npx ng test` — run configured unit tests.

## Configuration
Keep environment-specific API URLs in the project's environment configuration. Do not commit secrets.
